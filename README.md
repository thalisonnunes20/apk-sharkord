# Aplicativo Mobile para Sharkord

**Aviso Importante:** Este projeto não é uma cópia, um fork (bifurcação) ou um projeto concorrente do Sharkord. Trata-se unicamente de um cliente mobile (wrapper/web app Android) desenvolvido para facilitar a utilização da interface web original. Este projeto foi feito sem quaisquer fins lucrativos, sendo totalmente código aberto e de livre acesso para a comunidade.

---

## O Que é Este Projeto?

O Aplicativo Mobile para Sharkord é uma solução baseada em Capacitor que encapsula a interface da web de qualquer servidor Sharkord auto-hospedado em um formato de aplicativo Android (`.apk`) nativo. 

O Sharkord, por padrão, é acessado através de navegadores de internet. Porém, para usuários que preferem a sensação de um aplicativo dedicado no celular — com ícone na tela inicial, acesso fácil e gerenciamento de permissões nativo —, esta aplicação atua como a ponte ideal.

### Como Funciona

Ao abrir o aplicativo pela primeira vez, você será recebido por uma tela de configuração limpa, responsiva e moderna que solicita o endereço (URL) do seu servidor Sharkord pessoal. Uma vez inserido, o aplicativo salvará essa informação localmente. Nas próximas vezes em que você iniciar o aplicativo, ele pulará a etapa de configuração e o conectará automaticamente (auto-login) de volta ao seu servidor.

### Funcionalidades Integradas

- **Permissões Nativas Otimizadas:** O aplicativo é pré-configurado para interagir com o Android e autorizar corretamente o uso de microfones e câmeras, poupando o usuário de falhas de permissão em navegadores mobile.
- **Auto-Login:** Memória persistente inteligente que reconecta o usuário automaticamente ao último servidor logado.
- **Interface Imersiva e Estática:** O aplicativo bloqueia os movimentos indesejados e puxões de tela padrões dos navegadores (rubber-banding), garantindo que a tela fique 100% estática e imersiva como um aplicativo nativo legítimo.
- **Layout Adaptativo:** Sem barras de rolagem desnecessárias. A interface de login se adapta aos menores ou maiores visores de smartphones.
